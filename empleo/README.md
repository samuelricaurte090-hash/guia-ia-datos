# Empleo

Aquí va todo lo que sirve para postular: las vacantes que revises, tu CV y las notas de entrevistas.

## vacantes.csv

En la semana 2 anota 20 vacantes junior de datos, una por fila. En la semana 3 las vas a analizar con pandas para saber qué habilidades pide el mercado colombiano y ajustar tu estudio a eso.

| Columna | Qué escribir | Ejemplo |
|---|---|---|
| fecha | Día en que la viste | 2026-10-28 |
| empresa | Nombre de la empresa | |
| cargo | Título exacto de la vacante | Analista de Datos Junior |
| ciudad | Ciudad o "Remoto" | Bogotá |
| modalidad | Presencial, híbrido o remoto | Híbrido |
| salario_mensual_cop | Solo el número, vacío si no lo dicen | 3500000 |
| experiencia_anios | Años que piden, 0 si no piden | 1 |
| ingles | Nivel que piden, vacío si no piden | B1 |
| habilidades | Separadas por barra vertical | SQL\|Excel\|Power BI\|Python |
| enlace | URL de la vacante | |
